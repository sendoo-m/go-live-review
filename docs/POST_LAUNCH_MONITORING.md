# خطة المراقبة والتشخيص بعد الإطلاق (Post-Launch Monitoring Plan)
## Daleel Ay Khidma • 7-Day Real-Time Observability & KPI Tracking

---

## 1. جدول المراقبة المكثفة لأول 24 ساعة (First 24-Hour Hourly Cadence)

خلال الساعات الـ 24 الأولى من الإطلاق، يتم تفقد المؤشرات كل ساعة وفق الجدول التالي:

```
┌────────────────────────────────────────────────────────────────────────┐
│               جدول الفحص اللحظي للساعات الأولى من الإطلاق               │
├───────────────────┬────────────────────────────────────────────────────┤
│ كل 15 - 30 دقيقة  │ • لوحة تقارير الأعطال الفورية (Crashlytics / Sentry) │
│                   │ • صندوق بريد الدعم المعتمد (sendoo.m@gmail.com)    │
├───────────────────┼────────────────────────────────────────────────────┤
│ كل ساعة           │ • نسبة أخطاء الخادم (API HTTP 5xx / 4xx error rate)│
│                   │ • معدل نجاح رفع وتنزيل صور Cloudflare R2           │
│                   │ • معدل أداء محرك البحث والفلترة الجغرافية          │
├───────────────────┼────────────────────────────────────────────────────┤
│ كل 4 ساعات        │ • تقييمات وتعليقات المتاجر (Store Reviews & Star Rating)│
│                   │ • معدل تجميد التطبيقات (ANR & Main Thread Freezes) │
│                   │ • إحصائيات تسجيل دخول المستخدمين والتجار           │
└───────────────────┴────────────────────────────────────────────────────┘
```

---

## 2. جدول المراقبة اليومية للأيام (2 إلى 7) (Days 2–7 Daily Monitoring Cadence)

- **الساعة 09:00 صباحاً:** مراجعة تقرير الاستقرار اليومي ومعدل Crash-Free خلال الـ 24 ساعة الماضية.
- **الساعة 02:00 ظهراً:** فحص استهلاك خوادم قواعد البيانات وسعة التخزين في Cloudflare R2.
- **الساعة 06:00 مساءً:** فرز تذاكر الدعم واستفسارات التجار والرد عليها.
- **الساعة 10:00 مساءً:** اتخاذ قرار رفع نسبة الـ Staged Rollout لليوم التالي بناءً على معايير الجودة.

## 3. مصفوفة مؤشرات الأداء المستهدفة والعتبات الحرجة (KPIs & Thresholds)

| المؤشر التقني (Metric) | القيمة المستهدفة (Target) | عتبة التحذير (Warning) | العتبة الحرجة المانعة (Blocker) |
| :--- | :---: | :---: | :---: |
| **Crash-Free Sessions** | `>= 99.5%` | `99.0% - 99.4%` | `< 98.5%` |
| **ANR / UI Freezes** | `< 0.05%` | `0.1% - 0.2%` | `> 0.3%` |
| **Login / Auth Failures** | `< 0.2%` | `0.5% - 1.0%` | `> 2.0%` |
| **API Error Rate (5xx)** | `< 0.1%` | `0.2% - 0.5%` | `> 1.0%` |
| **R2 Media Upload Failures** | `< 0.5%` | `1.0% - 2.0%` | `> 3.0%` |
| **R2 Image Delivery Latency** | `< 200ms` (Edge CDN) | `300ms - 600ms` | `> 1000ms` |
| **Search Zero-Result / Failure** | `< 1.0%` | `2.0% - 4.0%` | `> 5.0%` |
| **Deep Link Routing Failures** | `0%` | `0.1% - 0.5%` | `> 1.0%` |
| **Store Rating Average** | `>= 4.6 ★` | `4.0 ★ - 4.5 ★` | `< 3.8 ★` |

## 4. مستويات خطورة المشاكل وسرعة الاستجابة (Incident Severity & SLA)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        مستويات تصنيف البلاغات والأعطال                 │
└────────────────────────────────────────────────────────────────────────┘
          │                                           │
  ┌───────▼────────┐                         ┌────────▼────────┐
  │  🔴 P0 - BLOCKER  │                         │ 🟡 P1 - WARNING │
  └───────┬────────┘                         └────────┬────────┘
          │                                           │
  • انهيار متكرر عند الفتح                     • بطء ملحوظ في تحميل الصور
  • تعطل تسجيل الدخول أو CRM                  • خلل في عرض خريطة معينة
  • فشل الرفع لـ Cloudflare R2                • أخطاء نصوص غير مؤثرة وظيفياً
  ┌───────┴────────┐                         ┌────────┴────────┐
  │ إيقاف الإطلاق  │                         │ معالجة خلال     │
  │ + Hotfix فوري  │                         │ 24 إلى 48 ساعة  │
  │ خلال < 6 ساعات │                         │ دون إيقاف الطرح │
  └────────────────┘                         └─────────────────┘
```

- 🟢 **P2 - Minor / Acceptable Noise:** ملاحظات شكلية بسيطة، استفسارات استخدام عادية، أو أخطاء ناتجة عن انقطاع اتصال محلي من جهاز المستخدم (تدرج في التحديث الدوري القادم).
