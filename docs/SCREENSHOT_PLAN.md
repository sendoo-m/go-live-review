## 4. إرشادات التصميم والبيانات النظيفة (Design & Clean Data Rules)
1. **الخطوط:** استخدام خط عربي عصري وواضح (مثل *Tajawal* أو *Cairo* أو *PingFang Arabic*).
2. **التباين اللوني:** خلفيات نظيفة (Dark Slate `#0F172A` أو Pure White `#FFFFFF`) مع تدرجات العلامة التجارية الزمردية (`#0F766E`).
3. **بيانات نظيفة وحقيقية:** 
   - أسماء محلات وأنشطة حقيقية وأنيقة (مثل: "مخبوزات الأصيل"، "مركز الشفاء التخصصي"، "إلكترونيات المستقبل").
   - أسعار ومنتجات منطقية وخالية من أي نصوص تجريبية مثل (Test / Lorem Ipsum / asdf).
   - تواريخ وساعات عمل واقعية ومنسقة.
